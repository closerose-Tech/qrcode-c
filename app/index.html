标准与算法说明

分级体系

整体等级取各参数等级的最低值（“木桶原则”），识读失败直接判 F。等级对应 4.0 / 3.0 / 2.0 / 1.0 / 0.0，并按 ISO/IEC 15415:2024 的连续分级方式给出一位小数。

ISO/IEC 15415（印刷 2D 符号）

  • 符号对比度 SC：Rmax−Rmin，A≥70%、B≥55%、C≥40%、D≥20%。
  • 调制度 MOD：每模块 MOD=2|R−GT|/SC，按纠错余量折算等级（A≥50%、B≥40%、C≥30%、D≥20%）。
  • 固定图形损伤 FPD：三个定位图案、定时图案、校正图案、静区的错误模块占比，取最差项（0%→A，≤9%→B，≤13%→C，≤17%→D）。
  • 轴向非均匀性 ANU：|X−Y|/((X+Y)/2)，A≤6%、B≤8%、C≤10%、D≤12%。
  • 网格非均匀性 GNU：模块中心对理想网格的最大偏移，A≤38%、B≤50%、C≤63%、D≤75%。
  • 未用纠错 UEC：(可纠码字数−已纠正码字数)/可纠码字数，A≥62%、B≥50%、C≥37%、D≥25%。

ISO/IEC 29158（AIM-DPM）

面向激光蚀刻、针点压印、电化学打标等直接零件标识：以反射率分布统计量作为阈值，计算单元对比度 CC（A≥30%）、单元调制度 CM、最小反射率 MR（A≥20%），并以分布性损伤 DDG 反映多点分散损伤；其余参数与 15415 共用。同一图像用 29158 评估通常高于 15415。

ISO/IEC 18004（QR Code）

按符号结构生成功能图形期望图案，读取格式信息（BCH 15,5）、掩模号与纠错块结构；按码字逐个执行 Reed-Solomon 伴随式计算与 Berlekamp-Massey 求解，得到实际被纠正的码字数——UEC 为本机实测值而非估算。

ISO/IEC 15416 与 ISO/IEC 16022 的覆盖

一维条码（15416：边缘判定、最小反射率、最小边缘对比度、缺陷、可译码性）与 Data Matrix（16022：L 型定位、时钟轨、纠错余量）的质量分级与 15415 同源：反射率、采样孔径、静区与纠错余量的量测原则在本工具中已按 2D 符号实现。两者的专用解码与分级流程将在后续版本开放，当前版本对 QR Code 提供完整分级。

边界

手机成像缺少标定光源与标准孔径，绝对反射率不可溯源；本工具给出的是“可复现的相对评估”，适用于来料比对、批次趋势与制码工艺排查。正式验收请使用具备 45°/0° 照明与标定白板的条码验证器。
